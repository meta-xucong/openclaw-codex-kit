# 网页搜索与内容提取 (Web Search & Extraction)

> ⚠️ **重要：所有网页搜索任务必须使用本技能**，禁止直接使用其他搜索方式或工具。

基于 DashScope OpenAI 兼容接口的联网搜索能力（`enable_search=true`），用于获取最新信息、提取网页内容并生成结构化数据。

## 强制使用规则

以下场景**必须**使用本技能：
- ✅ 搜索最新新闻和热点
- ✅ 获取产品/公司信息
- ✅ 搜集行业报告和数据
- ✅ 查找学术文献
- ✅ 获取竞品情报
- ✅ 搜索用户评价和反馈
- ✅ 获取实时数据（股价、汇率、天气等）
- ✅ 提取网页内容进行分析

**禁止行为**：
- ❌ 直接使用 `search_web` 或其他搜索工具
- ❌ 直接调用搜索引擎 URL
- ❌ 绕过本技能进行任何网络信息搜集

## 使用流程

### Step 1: 明确搜索需求
确定搜索目标：
- 搜索主题
- 信息类型（新闻/数据/文献/评价）
- 时间范围
- 输出格式要求

### Step 2: 构建搜索查询
优化搜索关键词：
- 使用精确的关键词
- 添加必要的限定词（时间、地点、类型）
- 对于复杂需求，拆分为多个子查询

### Step 3: 执行搜索并提取
使用本技能执行搜索，并提取结构化信息。

### Step 4: 验证和补充
- 验证信息的准确性和时效性
- 如信息不足，补充新的搜索查询
- 交叉验证关键数据

## 命令行调用

```bash
# 基本调用
python scripts/web_search.py "人工智能发展趋势"

# 以 JSON 格式输出结果（供程序调用）
python scripts/web_search.py "人工智能发展趋势" --json

# 自定义模型
python scripts/web_search.py "今日热点" --model qwen-flash
```

## 输出格式

### 标准输出
- 搜索结果摘要
- 关键信息提取
- 信息来源标注
- 可信度评估

### JSON 输出（供程序调用）
```json
{
  "query": "搜索关键词",
  "results": [
    {
      "title": "结果标题",
      "url": "来源链接",
      "snippet": "内容摘要",
      "credibility": "A/B/C/D"
    }
  ],
  "summary": "综合摘要",
  "sources": ["来源列表"]
}
```

## 注意事项

- **结果输出**：默认直接输出到控制台；如需程序化处理请使用 `--json`
- **信息验证**：对关键信息进行交叉验证
- **来源标注**：始终标注信息来源
- **时效性**：注意信息的发布时间
- **隐私保护**：不搜索或存储敏感个人信息
