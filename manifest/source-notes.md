# 整理说明

本包整理了可供 Codex 使用的 Agent 配置、技能说明、脚本、参考资料和部署工具。

## 已迁移

- 通用技能和专业工作流技能目录
- 文档、云盘、权限、知识库等外部工具的工作流说明
- Canvas、Healthcheck、Node Connect、Weather 等工具类技能
- 7 个面向 Codex 的 Agent TOML 配置
- Agent 已统一改为“功能名 + 官”：全能官、研究官、创作官、投资官、增长官、生活官、办公官

## 未迁移

- 任何主配置、凭据文件和 `.env` 中的敏感配置
- API Key、Gateway Token、第三方服务凭据
- 会话历史、记忆数据库、运行日志和本地缓存
- 未检测到的 MCP Server 配置
- 技能运行缓存、Seedance 历史任务状态、个人文章草稿和生成图片

这样做的目标是让仓库可以安全复盘和跨电脑部署技能/Agent，而不是复制一份带凭据的完整运行环境。
