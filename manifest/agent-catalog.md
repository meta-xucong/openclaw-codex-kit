# Codex 助理 Agent 目录

这套 Agent 使用统一的“功能名 + 官”命名方式。调用时优先使用下表中的正式名称。

## 一览

| 图标 | Agent | 主要负责 | 快速调用词 |
|---|---|---|---|---|
| 🧭 | 全能官 | 综合统筹、跨领域任务、长期协作 | 全能、统筹、综合处理 |
| 🔎 | 研究官 | 学术、行业、竞品、用户和市场研究 | 研究、调研、竞品、行业 |
| ✍️ | 创作官 | 公众号、小红书、文案、脚本和提示词 | 创作、写作、文案、脚本 |
| 📈 | 投资官 | A股、基金、宏观、创业投资和资产配置 | 投资、股票、基金、配置 |
| 🚀 | 增长官 | 用户痛点、产品定位、获客、转化和变现 | 增长、商业、获客、转化 |
| 🌿 | 生活官 | 健身、饮食、旅行、天气和复盘 | 生活、健身、饮食、旅行 |
| 📋 | 办公官 | 文档、表格、PDF、PPT、邮件和会议 | 办公、文档、表格、会议 |

## 调用模板

### 全能官

```text
请启动并使用自定义 Agent「全能官」，统筹完成下面这个综合任务：
……
```

适合需求还没有拆清楚，或同时涉及研究、写作、文件和计划的任务。

### 研究官

```text
请启动并使用自定义 Agent「研究官」，研究：……
请区分事实、来源和推测，并给出结论、证据、风险和行动建议。
```

适合行业研究、竞品分析、学术检索、用户研究和市场规模测算。

### 创作官

```text
请启动并使用自定义 Agent「创作官」，把下面材料改写成：……
请先给可以直接使用的成稿，再说明结构和传播逻辑。
```

适合公众号、小红书、短视频脚本、广告文案、图片提示词和视频提示词。

### 投资官

```text
请启动并使用自定义 Agent「投资官」，分析：……
请给出结论、分析逻辑、主要风险、数据日期和适用边界，不承诺收益。
```

适合股票、基金、宏观周期、创业项目和家庭资产配置。

### 增长官

```text
请启动并使用自定义 Agent「增长官」，为这个产品设计增长方案：……
请按痛点、定位、获客、转化、留存和实验指标展开。
```

适合商业模式、Offer、定价、流量、销售转化和增长实验。

### 生活官

```text
请启动并使用自定义 Agent「生活官」，帮我制定：……
请给出清单、时间表、预算或下一步行动，并说明健康信息边界。
```

适合健身、饮食、旅行、天气和日常复盘。

### 办公官

```text
请启动并使用自定义 Agent「办公官」，处理下面的文件/数据/会议记录：……
请直接输出可交付结果，并列出决定、负责人和截止时间。
```

适合 Excel、Word、PDF、PPT、邮件、会议纪要和文件整理。

## 两种工作方式

### 直接启动

在新任务第一句话中点名 Agent：

```text
请启动并使用自定义 Agent「研究官」……
```

### 委派给 Agent

在当前对话中让主 Agent 委派：

```text
请把这个任务交给「研究官」独立完成，返回证据和结论；你最后再帮我汇总。
```

如果要并行处理：

```text
请并行委派：研究官负责市场研究，增长官负责商业化方案，创作官负责最终文案。
```
